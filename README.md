# Engine-Labor

Schau einer einfachen Schach-Engine beim Rechnen zu. Für die Projektwoche Schach: Wie Engines denken.

- Rechentiefe 1 bis 4 Halbzüge, reine Minimax-Suche, bewertet nur Material.
- Spielbaum in drei Spalten, Varianten als Pfeile auf dem Brett.
- Eigene Stellungen lassen sich aufbauen und werden nur im eigenen Browser gespeichert.
- Keine Anmeldung, keine Datensammlung, keine externen Schriften oder Skripte.

Die ganze Anwendung steckt in `index.html`.
